# Portfolio — BALOGOU Eustache

Portfolio personnel en HTML, CSS et JavaScript vanilla, conçu avec une direction artistique dark premium.

## Lancer en local
Ouvrir simplement `index.html` dans un navigateur ou lancer un serveur statique local.

## Structure
- `index.html` : contenu et sections du portfolio
- `styles.css` : design responsive et animations
- `script.js` : navigation mobile, filtres projets et animations d'apparition
- `moi.png` : portrait déjà présent dans le dépôt

## Déploiement
Projet statique compatible avec Vercel. Aucun secret ni variable d'environnement requis.

## Transparence
Les projets sont identifiés comme personnels, collaboratifs ou exploratoires. Les dépôts privés restent privés. Les liens de démonstration sont fournis lorsqu'ils sont disponibles.
