# Portfolio — BALOGOU Eustache

Portfolio professionnel personnel, en français, réalisé en HTML, CSS et JavaScript natifs.

## Fonctionnalités
- Direction artistique dark premium et responsive.
- Présentation, compétences, projets, parcours et contact.
- Filtres de projets, navigation mobile et animations d'apparition.
- Respect de la préférence système « réduire les animations ».
- Aucune dépendance de build nécessaire.

## Lancer en local
Ouvrir `index.html` dans un navigateur ou utiliser un serveur local statique.

## Personnalisation
- Contenu : `index.html`
- Styles : `styles.css`
- Interactions : `script.js`
